# Building Tier Matrix (Design Roadmap)

This is a readability-first design table derived from BUILDING_TIER_MATRIX.csv.

How to read this table:
- Each row is one building chain, not one isolated building.
- The tier columns show the intended upgrade name for that chain at each progression step.
- Empty tier cells mean that chain does not exist at that tier. Example: Mine starts at Tier 2, and Builder's Hut starts at Tier 3.
- If the same name appears in two tiers, that means the chain keeps the same visible name while the effect upgrades behind the scenes.
- The final column explains the gameplay effect or unit role that chain should provide.
- This document is the design reference first; code implementation should follow the approved names and effects here.

Tier rules:
- Tier 1 and Tier 2 are the early kingdom era.
- Tier 3 is the point where advanced infrastructure and military lines begin to unlock.
- Tiers 4 to 10 are later growth stages that should feel more gradual and more advanced, not giant jumps.
- For chains that begin later, earlier tier cells stay blank instead of forcing a fake starter building.
- For upgrade-only support buildings, the chain should improve efficiency, capacity, or quality rather than changing the core gameplay loop.
